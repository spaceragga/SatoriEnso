# Satori Enso Studio

Satori Enso — это веб-студия, названная в честь двух фундаментальных понятий дзен-буддизма: внезапного, интуитивного пробуждения (Satori) и круга бесконечности, целостности и несовершенной красоты (Enso). Название декларирует подход, при котором точное понимание сути (Satori) воплощается в цельный, живой и открытый к бесконечности цифровой продукт (Enso) — одним точным движением, без лишнего шума.
